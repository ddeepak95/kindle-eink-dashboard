# Quote sources

Motivating excerpts from public-domain works, verified against these full texts.
Poetry line breaks are flattened for the dashboard's one-line quote format.

- Ralph Waldo Emerson, Compensation, Circles, and Self-Reliance, in Essays, First Series:
  https://www.gutenberg.org/cache/epub/2944/pg2944-images.html
- Louisa May Alcott, Little Women:
  https://www.gutenberg.org/files/514/514-h/514-h.htm
- William Ernest Henley, Invictus; Alfred Tennyson, Ulysses;
  Henry Wadsworth Longfellow, A Psalm of Life; Edwin Markham, Preparedness,
  collected in It Can Be Done:
  https://www.gutenberg.org/cache/epub/10763/pg10763-images.html

Edit layout/quotes.txt, then run node tools/sync-quotes.cjs to update
data/quotes.txt and the file-based preview snapshot. Published layout releases
remain immutable; a future release will include the updated fallback quotes.
